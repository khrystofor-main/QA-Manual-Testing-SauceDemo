# Test plan - SauceDemo

## 1. Introduction 
SauceDemo - an online store created for educational purposes. Goal - test the main features: login, catalog, cart, checkout.

## 2. Scope
### In scope
- Login
- Products / sorting
- Cart
- Checkout
- Logout / menu

### Out of scope
- Stress testing
- Security
- Backend / API

## 3. Test Approach
Manual type testing. Writing test cases, running manualy, logging bugs in bug reports.

## 4. Test Environment
- Browser: Chrome 153
- Os: Windows 11
- url: https://www.saucedemo.com

## 5. Test Data
Users: standard_user, locked_out_user, problem_user.
Password: secret_sauce.

## 6. Entry / Exit Criteria
- Entry: App is available, test cases are ready
- Exit: All test cases have been run, critical bugs have been documented

## 7. Deliverables
Test cases, bug reports, test summary report.
